# Embedded Firmware Development

Welcome to my embedded firmware development portfolio!

This repository contains a collection of my firmware projects developed for **ARM and AVR microcontrollers**, demonstrating my practical experience in low-level embedded programming, hardware control, and microcontroller-based system development.

My primary focus is on understanding and utilizing microcontroller hardware at the register level, developing efficient and reliable firmware, and implementing solutions that combine hardware and software into functional embedded systems.

## Technical Expertise

My projects demonstrate practical experience in the following areas:

- **Low-Level Programming:** Direct register-level programming, peripheral configuration, and microcontroller hardware control.
- **Bare-Metal Development:** Firmware development without an operating system, with direct control over hardware resources, interrupts, and execution flow.
- **Microcontroller Architectures:** ARM Cortex-M and AVR microcontrollers.
- **Communication Protocols:** UART, SPI, I²C, CAN, and other peripheral communication interfaces.
- **Interrupt Handling:** Interrupt Service Routines (ISRs), external interrupts, and hardware event management.
- **Timers and Counters:** Timer configuration, PWM generation, input capture, and output compare functionality.
- **RTOS:** Familiarity with real-time operating system concepts, task management, synchronization, and concurrent execution.
- **Hardware Integration:** Interfacing with sensors, displays, memory devices, external ICs, and other electronic components.

## Engineering Approach

I believe that professional embedded development requires more than simply making code work. It requires a solid understanding of the underlying hardware, efficient resource utilization, and careful consideration of system reliability and performance.

My approach to firmware development is based on:

- Understanding microcontroller architecture and peripheral operation at the hardware level.
- Writing structured, maintainable, and reusable C/C++ code.
- Minimizing unnecessary dependencies and maintaining control over hardware resources.
- Debugging and troubleshooting both hardware and software issues.
- Developing solutions with practical hardware constraints in mind.
- Taking ownership of engineering tasks, from initial analysis to implementation and verification.

## Project Portfolio
